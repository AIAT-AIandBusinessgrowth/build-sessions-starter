# Build Sessions Starter

[English](README.md) · **Hrvatski**

Tvoj prvi alat s AI agentom, u jednom danu. Ne moraš znati programirati.

Prije radionice: [upute za pripremu](docs/setup-guide-hr.pdf) i [kratke upute](docs/cheat-sheet-hr.pdf). Oboje postoji i na engleskom: [setup guide](docs/setup-guide-en.pdf), [cheat sheet](docs/cheat-sheet-en.pdf). Odaberi jezik koji ti više odgovara.

## Tri koraka

1. **Preuzmi ovu mapu.** Klikni **Code → Download ZIP** i raspakiraj ZIP. Ako koristiš Git, može i `git clone`.
2. **Otvori je** u alatu Claude Code ili Codex. U aplikaciji: otvori mapu. U terminalu: uđi u mapu i upiši `claude` ili `codex`.
3. **Upiši `kreni`** (ili `start` za engleski).

Agent se upoznaje s tobom, pomaže ti pronaći ideju, s tobom je planira, izrađuje prvu verziju i provjerava je. Ti odlučuješ, a posao radi agent.

## Riječi koje uvijek možeš upisati

`dalje` (next) · `natrag` (back) · `objasni` (explain) · `provjeri` (check) · `gdje smo` (where are we)

## Što je ovdje

| Datoteka ili mapa | Što je to |
|---|---|
| `AGENTS.md` | Kako te agent vodi. Claude Code je čita preko `CLAUDE.md`. |
| `me.md` | Što agent zna o tebi. Agent je sam popunjava. |
| `rules/` | Tri pravila kojih se agent drži: samo izmišljeni podaci, završeno znači provjereno, mali koraci. |
| `projects/` | Jedna mapa za svaku ideju, s tvojim planom i tvojim alatom. |
| `notes/learned.md` | Dvije rečenice nakon svakog koraka: što je napravljeno i što valja zapamtiti. |
| `examples/ana/` | Gotov primjer s izmišljenim podacima. Reci „isprobaj primjer Ana“. |

## Prvo pravilo

Samo izmišljeni podaci. Bez stvarnih imena, klijenata, datoteka s posla, lozinki i ključeva. Osobne AI pretplate nemaju ugovor o obradi podataka s tvojom organizacijom.

## Kako nastaviti

Ista mapa, isti plan. Ponovno otvori agenta i reci `gdje smo`. Više vježbi: [AI:AT Build Sessions](https://github.com/AIAT-AIandBusinessgrowth/aiat-build-sessions).

Dijelimo ovo kakvo jest, bez podrške. Greške i ideje prijavi kao issue.

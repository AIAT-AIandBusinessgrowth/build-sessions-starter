# Example: Ana

Ana looks after four rooms with temperature sensors. Every sensor saves one file a day, so there are 40 files since the last report (4 rooms, 10 days). Every Monday her boss asks: was anything odd? Ana used to open all 40 files by hand.

Say "try the Ana example" and watch what the agent does. Then ask: "How many rows did you read, and is anything odd?" Two problems are hidden in the data.

All data is made up.

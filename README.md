# Build Sessions Starter

Hrvatski: [README.hr.md](README.hr.md)

Your first tool with an AI agent, in one day. You don't need to know how to code.

## Three steps

1. **Get this folder.** Click **Code → Download ZIP** and unzip it. With Git: `git clone` works too.
2. **Open it** in Claude Code or Codex. In the app: open the folder. In the terminal: go into the folder and type `claude` or `codex`.
3. **Type `start`.** Prefer Croatian? Type `kreni`, and the agent works in Croatian.

The agent gets to know you, helps you find an idea, plans it with you, builds a first version and checks it. You decide, it does the work.

## Words you can use any time

`next` · `back` · `explain` · `check` · `where are we`

## What is in here

| File or folder | What it is |
|---|---|
| `AGENTS.md` | How the agent guides you. Claude Code reads it through `CLAUDE.md`. |
| `me.md` | What the agent knows about you. It fills this in. |
| `rules/` | Three rules the agent follows: only made-up data, done means checked, small steps. |
| `projects/` | One folder per idea, with your plan and your tool. |
| `notes/learned.md` | Two sentences after each step: what you did and what to remember. |
| `examples/ana/` | A finished example with made-up data. Say "try the Ana example". |

## Rule one

Only made-up data. No real names, customers, files from work, passwords or keys. Personal AI subscriptions have no data processing agreement with your organisation.

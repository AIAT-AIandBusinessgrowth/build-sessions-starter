# Rule one: only made-up data

- Use invented data only. No real names, customers, e-mail addresses, files from work, screenshots with real data, passwords or keys.
- Why: personal AI subscriptions have no data processing agreement with your organisation. What you type may leave your laptop.
- Column names are enough. The agent invents the values. E-mail addresses end in `@example.com`.
- If real data shows up anyway: stop, do not repeat it, replace it with made-up values.
